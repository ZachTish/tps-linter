# TPS Linter 0.3.0

TPS Linter `0.3.0` is a backward-compatible feature release that adds an optional bottom-aligned ATX heading hierarchy to the explicit current-note workflow.

## User-visible changes

- Adds **Push heading hierarchy down to H6** under the Headings destination.
- Keeps the option disabled by default and leaves the existing H1/H2 top-down behavior unchanged.
- Makes a standalone heading such as `## Test` become `###### Test` when the option is enabled.
- Normalizes source-level jumps to one structural nesting step, then shifts the complete visible outline so its deepest nesting level is H6.
- Preserves root, sibling, and parent/child relationships and remains idempotent on repeated cleaning.
- Excludes headings inside YAML, fenced or indented code, math, multiline comments, raw HTML, and Templater regions from the outline calculation.
- Keeps visible headings with inline protected syntax in the hierarchy while preserving their protected text.
- Hides **First heading level** while H6 alignment is active without erasing the saved H1/H2 choice.

## Compatibility and migration

- Minimum supported Obsidian version: `1.10.0` (unchanged).
- Persisted settings advance from schema v2 to v3.
- Existing settings and exclusions are preserved, including template exclusions intentionally removed after the v2 migration.
- Existing installations receive `pushHeadingHierarchyToH6: false`.
- The option remains dormant when **Normalize heading levels** is off.
- No note-data migration is required.
- No automatic save/create/modify/file-open mutation hooks or whole-vault cleanup commands were added.

## Safety and known limitations

- H6 alignment runs only during an explicit Clean action because changing heading levels can affect fragment links and TPS heading consumers.
- The shift is global across the complete visible ATX outline. In an uneven tree, a shallow leaf may remain above H6 when another branch is deeper; this preserves sibling and parent relationships.
- Setext headings remain unchanged.
- Native iOS interaction remains a separate device confirmation.
