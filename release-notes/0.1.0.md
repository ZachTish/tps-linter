# TPS Linter 0.1.0

TPS Linter `0.1.0` is the initial lightweight TPS-specific filename and Markdown cleanup foundation.

## User-visible changes

- Adds **Check current note** for a read-only report and **Clean current note** for one explicit, guarded mutation.
- Adds manual filename cleanup that preserves TPS date, version, numeric-prefix, punctuation, Unicode, and emoji naming patterns.
- Refuses empty, reserved, case-only, colliding, or TPS Global Context Menu-owned filename mutations.
- Adds conservative Markdown cleanup for whitespace-only blank lines, an optional missing final newline, and opt-in nonblank trailing whitespace cleanup.
- Preserves BOMs, existing line-ending bytes, YAML frontmatter, fenced code, raw protected HTML blocks, multiline Templater regions, Markdown hard breaks, and TPS inline data.
- Adds a flat, responsive settings page with actions first, direct TPS Global Context Menu ownership handoff, explicit rule toggles, exclusions, and off-by-default diagnostics.

## Compatibility and migration

- Minimum supported Obsidian version: `1.10.0`.
- No settings or data migration is required.
- The plugin is mobile-capable and has no Node- or Electron-only runtime dependency.
- There are no automatic mutation hooks or whole-vault cleanup commands in this release.

## Known limitations

- TPS Global Context Menu remains the automatic title/filename owner. TPS Linter reports but does not apply filename changes while GCM automatic rename is active.
- Automatic and batch cleaning, a visual diff, frontmatter formatting, and broader Markdown rules are deferred.
- Native iOS interaction remains a separate device confirmation.
