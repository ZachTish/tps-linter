# TPS Linter 1.0.0 — explicit cleanup only

Saving, focusing, opening, and syncing notes no longer trigger TPS Linter cleanup. Use **Check current note** for a read-only report and **Clean current note** to apply configured rules. File-menu and settings actions remain available.

This is a major behavior change: automatic save/focus cleanup and its settings have been removed, not replaced with a disabled background loop. Existing notes and settings files are not migrated or deleted. Historical automatic-cleanup flags remain inert. Downgrading to 0.8.0 can reactivate those saved flags; review them before enabling the older version.

## Removed machinery

- Save/focus scheduler, queued automatic writer, feedback state, and GCM automatic-mutation integration.
- Two automatic DOM subscriptions (save shortcut and focus), two window lifecycle subscriptions, and one layout-ready hook: all removed. The explicit file-menu listener remains.
- One debounce scheduling owner removed. No replacement timers, pollers, or repair service.
- Runtime source: 8 lines added, 990 removed; net reduction 982 lines. Tests/documentation/generated bundles excluded.

## Validation

- 258 unit/runtime tests and 18 settings/source contracts passed; TypeScript and separate production-mode build passed.
- 10,003 historical differential cases passed against the exact 0.5.5 source baseline.
- Actual entry-point harness: 100 bursts of seven events produced zero body reads, inventories, writer attempts, settings saves, or timers; explicit Check/Clean and unload during initialization retained coverage.
- Final 1.0.0 artifact deployed/reloaded in Obsidian Plugin Test Vault. Installed Check preserved the synthetic note byte-for-byte; Clean applied heading capitalization and preserved prose; repeating Clean made no further change. Original active note restored and fixture archived.
- Four settings destinations previously inspected without note writes or provider requests. Layout unchanged apart from removing the automatic controls.
- Combined cleaned TPS foreground measurements, five samples: startup median 6084.7 ms (previous 6066.2 ms), 20-note navigation median 838.9 ms (previous 897.2 ms). These are suite-wide test-vault measurements, not Linter-only attribution or production-speed claims. Suite idle, typing, and simulated Sync checks observed no TPS maintenance writes; core saves/read-only indexing counted separately.

Requires Obsidian **1.10.0+**. Physical iPhone acceptance remains unverified. Tested in the test vault and ready for the user's BRAT pull; production has not been changed. The remaining TPS cleanup is not included in this standalone release.
